# アレクシアと風の羅針盤

風を一投、羅針盤から放つ。壁と岩で反射させながら灯石に風を通し、六つの浮島を結ぶ航路を取り戻す、ひとり用のブラウザゲームです。全18航路。初回の設計目安は10〜20分です。

## 遊ぶ

**単体版**　`play.html` をダウンロードし、ブラウザで開きます。HTMLに全画像・音源プログラム・航路を収録しています。GitHub上のファイル表示では「Download raw file」から保存できます。

**スマートフォン**　Web配信したトップページをSafariやChromeで開きます。静的ホスティングにはこのリポジトリのルートを置くだけです。GitHub Pagesを利用する場合は、リポジトリの **Settings → Pages → Deploy from a branch** でゲームを含むブランチと **/ (root)** を選んで保存し、表示されたサイトURLを開きます。公開範囲はホスティングの設定に従います。

**手元の開発サーバー**

```sh
python3 -m http.server 8080 --bind 0.0.0.0
```

PCで `http://localhost:8080/` を開きます。同じネットワークにいるスマートフォンからは、localhostの部分をPCのLANアドレスに置き換えてください。

## 操作

- 「冒険をはじめる」から最初の島へ出航します。
- 盤面を押し、指をずらして点線を合わせ、離すと発射します。狙う時間は自由です。
- 盤面下の左右ボタン、またはキーボードの左右キーで照準を調整できます。「風を放つ」または盤面にフォーカスしてSpaceで発射します。
- 二つ目の島を終えると、飛行中のタップまたはSpaceで「風の輪」が開きます。一投につき一度です。
- すべての灯石をともすとクリアです。目標手数以内で風印三つ、目標＋2手以内で二つ、それ以上で一つ。手数制限はありません。
- 音声は右上で切り替えます。音楽と効果音はWeb Audioで合成します。
- 各投が止まった時点で、その航路の灯石・手数・向きを自動保存します。飛行中に閉じると直前の投から再開します。記録は利用中のブラウザと配信元に紐づきます。保存できない環境でも、ページを開いている間は最後まで遊べます。
- 踏破した島は「航海手帳」から再訪できます。新しい力は過去の航路にも適用されます。

## 実装と素材

ゲーム本体はHTML、CSS、JavaScriptで動きます。通常版は画像を個別に読み込み、単体版は同じソースから生成します。

| ファイル | 内容 |
| --- | --- |
| `index.html`、`style.css` | タイトル、航路図、各画面のレイアウト |
| `data.js` | 島の物語と18航路の手配置 |
| `engine.js` | 発射、反射、分岐、転移、点灯判定 |
| `board.js` | 盤面描画、タッチとキーボード、連灯演出 |
| `presentation.js` | 海図の描画、アイコン、音楽・効果音 |
| `game.js` | 航海の進行、記録、手帳、エンディング |
| `assets/` | WebPイラスト、羅針盤マーク |
| `play.html` | 配布用の単体版 |

アレクシアは提供画像 `file_00000000d23c8211b47be3d75cb176d3.png` を透過WebPへ変換したものです。空景と六つの島の挿絵は本作向けに生成しました。盤面、航路、音楽、効果音は本作用のプログラムで制作しています。設計意図は [DESIGN.md](DESIGN.md) にまとめています。

## 開発・検証

ルートディレクトリから実行します。ソースや素材を変更したら、単体版も再生成してください。

```sh
python3 tools/pack.py
node --test tests/game.test.js
```

ブラウザ検証にはPython版PlaywrightとChromiumを使用します。上記の開発サーバーを起動した状態で実行します。

```sh
python3 tests/browser.py
python3 tests/inputs.py
```

前者は新規記録から全18航路を実際にタッチ発射で進め、再読み込みからの復帰と結末を確認します。後者は単体版を読み込んで通信を切り、4画面サイズでタッチキャンセル・キー操作・ストレージ利用不可時の進行を確認します。
